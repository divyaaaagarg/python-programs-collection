# Python Programs Collection

A beginner-friendly collection of Python programs demonstrating loops, recursion, sequences, and data conversion.

## Programs
- `factorial.py` — calculates a factorial iteratively and validates input.
- `fibonacci.py` — prints the first `n` Fibonacci numbers.
- `structure_to_dictionary.py` — converts a simple structured record into a Python dictionary.
- `main.py` — small menu to run the examples interactively.

## Technologies
- Python 3

## Run locally
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:
   ```bash
   python main.py
   ```
   Or run any program individually, for example `python factorial.py`.

## Features
- Input validation for common invalid values.
- Clear functions and comments for learning.
- No third-party packages required.
